# 🧪 Manual Testing Project

A structured manual testing project focused on test planning and execution to ensure software quality. This repository includes a detailed **Test Plan** and a comprehensive set of **Test Cases** to validate core functionalities of the application under test.

---

## 📋 Test Plan

The Test Plan defines the overall approach to testing. It includes:

- Scope of testing  
- Objectives and deliverables  
- Testing strategy and levels  
- Roles and responsibilities  
- Test environment setup    
- Entry and exit criteria  
- Risk and mitigation plans  

📁 Location: [`/TestPlan/Manual_Test_Plan.md`](./TestPlan/Manual_Test_Plan.md)

---

## ✅ Test Cases

Test cases are written to verify key application workflows and edge cases. Each test case includes:

- Test case ID  
- Description  
- Preconditions  
- Test steps  
- Expected results  
- Actual results  
- Status (Pass/Fail)
